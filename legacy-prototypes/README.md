# Protótipos Legados do CardVoz

Este diretório preserva os protótipos originais em HTML estático criados nas fases iniciais do projeto de extensão universitária:

- `index .html`: Visão inicial da lista de baralhos.
- `criar-baralho.html`: Formulário de criação de baralhos.
- `criar-cartao.html`: Formulário de cadastro de cartões com perguntas e respostas.
- `estudar.html`: Protótipo do fluxo de estudo com botões de revelação e avaliação (Acertei / Errei).

Estes arquivos foram mantidos para documentação e histórico acadêmico do projeto de acessibilidade. A aplicação oficial foi migrada para Next.js (App Router), TypeScript e Tailwind CSS na pasta `src/`.
